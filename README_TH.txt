วิธีอัปเดตเว็บไฮโลบน GitHub Pages (มือถือ)
1. แตกไฟล์ ZIP นี้ในโทรศัพท์
2. เปิด GitHub แล้วเข้า repository ชื่อ hua-koi
3. อัปโหลดไฟล์ 4 ไฟล์นี้ทับของเดิม: index.html, manifest.webmanifest, sw.js, icon.svg
4. กด Commit changes แล้วรอ GitHub Pages deploy สำเร็จ
5. เปิดเว็บเดิมใหม่ หากยังเห็นเวอร์ชันเก่า ให้ปิดแท็บแล้วเปิดใหม่ หรือรีเฟรช

วิธีเล่น
- กด “เขย่าลูกเต๋า”
- ใช้นิ้วลากแก้วโลหะไปทางขวาทีละช่วง เพื่อเปิดลูกเต๋าทีละลูก
- เสียงจะอ่านแต้มของลูกที่เปิด และเมื่อเปิดครบจะอ่านผลรวมกับสูง/ต่ำ
- ประวัติจะเก็บในเบราว์เซอร์ของโทรศัพท์เครื่องนี้ (localStorage)
- ผลรวม 3–10 = ต่ำ, 11–18 = สูง
