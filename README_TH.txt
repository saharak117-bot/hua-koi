อัปเดตเสียงและกติกาไฮโล
อัปโหลดไฟล์ 4 ไฟล์นี้ทับของเดิมใน GitHub repository hua-koi:
index.html, manifest.webmanifest, sw.js, icon.svg
จากนั้นกด Commit changes และรอ GitHub Pages deploy สำเร็จ

สิ่งที่เพิ่ม:
- กดปุ่มเขย่าทุกครั้งมีเสียงเขย่าหนึ่งชุดต่อหนึ่งครั้งที่กด
- สามารถกดเขย่าซ้ำได้ แม้ยังไม่ได้เปิดแก้วรอบก่อนหน้า (เริ่มรอบใหม่)
- เพิ่มแถบปรับระดับเสียงลูกเต๋า 0–100%
- เสียงพูดถูกตั้งให้เบากว่าเสียงลูกเต๋า
- ระบบสุ่มจะสุ่มใหม่อัตโนมัติถ้าผลรวมลูกเต๋า 3 ลูกเท่ากับ 11
- จำระดับเสียงและสถานะเปิด/ปิดเสียงไว้ในโทรศัพท์
