เว็บแอปหัวหรือก้อย

วิธีใช้:
1. แตกไฟล์ ZIP
2. นำไฟล์ทั้งหมดไปวางบนเว็บโฮสติ้งที่รองรับ HTTPS เช่น GitHub Pages
3. เปิด URL ของเว็บบน Chrome ใน Android
4. กดเมนู ⋮ > เพิ่มลงในหน้าจอหลัก (Add to Home screen)

หมายเหตุ: การเปิด index.html จากไฟล์ ZIP โดยตรงจะใช้ได้ แต่การติดตั้งเป็นเว็บแอปและใช้งานออฟไลน์ต้องโฮสต์ผ่าน HTTPS ก่อน
