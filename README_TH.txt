อัปเดตชื่อแอปและไอคอน
- เปลี่ยนชื่อแอปเป็น “คณิตคิดเร็ว”
- เปลี่ยนไอคอนเป็นรูปกระต่าย
- คงระบบเกมไฮโลลูกเต๋า 3 ลูกและประวัติเดิมไว้
- ปรับระยะเปิดแก้วให้เลื่อนพ้นพื้นที่เวทีอย่างชัดเจน

ให้อัปโหลดไฟล์ 4 ไฟล์นี้ทับของเดิมใน GitHub repository:
index.html, manifest.webmanifest, sw.js, icon.svg
จากนั้นกด Commit changes และรอ GitHub Pages deploy สำเร็จ
หากติดตั้งเป็นแอปไว้แล้ว ให้ปิดแอปแล้วเปิดใหม่ หรือรีเฟรชเว็บไซต์เพื่อรับชื่อและไอคอนใหม่


อัปเดตเพิ่มเติม:
- ระบบจะสุ่มลูกเต๋าใหม่จนกว่าผลรวมของลูกเต๋า 3 ลูกจะไม่เท่ากับ 10
- ผลรวม 10 จะไม่ถูกแสดงเป็นผลลัพธ์ในรอบใหม่
